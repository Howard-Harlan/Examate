# 富文本记法约定

本应用聊天界面会「真正渲染」以下内容:KaTeX 渲染数学公式与化学方程式,SmilesDrawer 渲染化学结构式。**务必用对记法,否则只会显示为纯文本。**

## 使用场景
输出涉及数学公式、化学方程式/化学式、化学结构式,或需要表格/代码等富文本时。

## 记法约定

### 数学公式(KaTeX)
- 行内:单 `$` 包裹,如 `$E=mc^2$`、`$\frac{a}{b}$`、`$\sum_{i=1}^n x_i$`。
- 块级:双 `$$` 独占整行:
  ```
  $$\int_0^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$$
  ```
- 支持完整 LaTeX 数学:分数、上下标、根号、求和/积分、矩阵(`\begin{pmatrix}...\end{pmatrix}`)、希腊字母、关系符等。高等数学请放心用块级公式。

### 化学方程式(mhchem,推荐)
化学反应、配平方程、离子式等,在 `$`/`$$` 内用 `\ce{}`:
- 行内:`$\ce{H2O}$`、`$\ce{SO4^2-}$`
- 反应:`$$\ce{2H2 + O2 ->[点燃] 2H2O}$$`、`$$\ce{CaCO3 ->[\Delta] CaO + CO2 ^}$$`
- 可逆:`$$\ce{N2 + 3H2 <=> 2NH3}$$`

### 化学结构式(SMILES,画出分子骨架)
**凡涉及有机物结构、苯环、环状化合物、官能团骨架,一律用 SMILES**(`$smiles{...}$` 或 ```smiles 代码块),不要用纯文字描述:
- 苯:`$smiles{c1ccccc1}`;乙醇:`$smiles{CCO}`;乙酸:`$smiles{CC(=O)O}`
- 甲苯:`$smiles{Cc1ccccc1}`;苯酚:`$smiles{Oc1ccccc1}`;吡啶:`$smiles{c1ccncc1}`
- 反应(反应物>条件>产物):`$smiles{CCO>>CC=O}`
- 只要给出正确 SMILES,渲染器就能画出结构(含苯环等环状化合物)。

### 何时用哪种
- 「反应 / 方程 / 配平 / 得失电子」→ mhchem(`\ce{}`)。
- 「结构 / 骨架 / 分子长什么样」→ SMILES(`$smiles{}`)。
- 二者可并用:先 `\ce{}` 写方程,再 `$smiles{}` 画关键结构。

### 其他 Markdown
粗体 `**x**`、斜体 `*x*`、列表 `-`/`1.`、引用 `>`、表格(标准语法)、代码块(三反引号,支持 json/csv/smiles/tex)。

## 注意
1. `$`/`$$` 必须成对;块级 `$$` 独占一行;SMILES 内不能有空格。
2. 不要用 `$` 表示货币金额(会误触发公式渲染)。
3. 流式生成期间公式暂显为纯文本,生成完成后自动渲染成图片,属正常现象。
4. 有机结构优先用 SMILES;用纯文字描述结构会导致「只显示文本」。
